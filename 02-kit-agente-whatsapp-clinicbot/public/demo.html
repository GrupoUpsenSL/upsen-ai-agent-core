Página de demostración

Esta página NO forma parte del widget: es solo un HTML normal en el que se ha incrustado el chat con una línea de código, exactamente como lo haría la web de un cliente.

Así se incrusta en cualquier página

<script src="/widget.js"
        data-agent-name="ClinicBot"
        data-color="#0ea5e9"
        data-welcome="¡Hola! Soy ClinicBot, ¿en qué puedo ayudarte?"></script>

El botón flotante debería haber aparecido abajo a la derecha. Haz clic para abrir el chat y escribe un mensaje — la respuesta la genera el mismo motor del agente que usa WhatsApp, con el mismo prompts/negocio.md.
